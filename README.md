# Repositório de Modelagens e Consultas SQL 📊

Bem-vindo ao meu repositório de estudos e práticas em Banco de Dados. Aqui reúno scripts que demonstram minha evolução técnica na linguagem SQL, focando em extração de dados eficiente, lógica de negócio e performance.

## 🚀 Objetivo
Este projeto serve como um portfólio técnico para demonstrar habilidades em:
* **Modelagem de Dados:** Estruturação de tabelas e relacionamentos.
* **Consultas Avançadas:** Uso estratégico de INNER, LEFT e RIGHT JOINs.
* **Análise de Desempenho:** Aplicação de funções de agregação (SUM, AVG, COUNT) e filtros complexos.
* **Resolução de Problemas:** Scripts voltados para KPIs reais, como Faturamento, Ticket Médio e Churn.

## 📂 Organização do Repositório
* `/Consultas`: Scripts com foco em DML (Data Manipulation Language).
    * `ExConsultas(joins,funcoesAgre).sql`: Meu "master script" com 15 níveis de consultas empresariais.
* `/Desafios`: Resolução de problemas práticos e cases de lógica.
* `/Modelagem`: (Opcional) Diagramas ERD ou scripts de criação de tabelas (DDL).

## 🛠️ Tecnologias Utilizadas
* **SQL** (Scripts testados e validados).
* **Conceitos de Banco de Dados Relacionais.**
* **Foco em Lógica de Negócio (BI & Backend).**

## 📈 Destaques Técnicos
No arquivo de consultas principais, destaquei métricas fundamentais para qualquer operação de TI/Negócios, como:
1.  **Gestão de Inadimplência** (identificação de pedidos sem pagamento).
2.  **Ranking de Vendas** (Top produtos via agregação).
3.  **Análise de Retenção** (clientes sem pedidos).
